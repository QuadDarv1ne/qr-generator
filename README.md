# QR Generator

Интерактивное веб-приложение для генерации настраиваемых `QR-кодов` с возможностью кастомизации внешнего вида, добавления логотипа и экспорта в нескольких форматах.

## Возможности

- **Различные типы данных**: `ссылки`, `текст`, `email`, `телефон`, `WiFi`, `vCard` и `другие`
- **Кастомизация дизайна**:
  - Цвета точек и фона
  - Формы точек (квадратные, круглые, каплевидные и др.)
  - Настройка рамок и ядер угловых маркеров
- **Добавление логотипа**: наложение логотипа на центр QR-кода
- **Настройка коррекции ошибок**: выбор уровня коррекции (`L`, `M`, `Q`, `H`)
- **Экспорт в форматах**: `PNG`, `SVG`, `PDF`
- **Готовые шаблоны для печати**: предопределённые пресеты с оптимизированными параметрами
- **Предпросмотр в реальном времени**: мгновенное обновление QR-кода при изменении настроек

## Быстрый старт

### Требования

- [Node.js](https://nodejs.org/) 18+ 
- [npm](https://www.npmjs.com/) или [pnpm](https://pnpm.io/)

### Установка

```bash
# Клонировать репозиторий
git clone https://github.com/<username>/qr-generator.git
cd qr-generator

# Установить зависимости
npm install

# Настроить переменные окружения
cp .env.example .env.local
# Заполнить DATABASE_URL в .env.local

# Запустить миграции базы данных
npx prisma migrate dev

# Запустить сервер разработки
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## Как это работает

1. **Выберите тип данных** — URL, текст, email, телефон, WiFi и т.д.
2. **Заполните форму** — введите нужные данные в соответствующие поля
3. **Настройте дизайн** — выберите цвета, форму точек, стиль угловых маркеров
4. **Добавьте логотип** (опционально) — загрузите изображение для центра QR-кода
5. **Настройте экспорт** — выберите формат и разрешение
6. **Скачайте** — сохраните QR-код на устройство
